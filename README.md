# AX 그룹 스터디

스터디마다 폴더가 하나씩 있습니다.

| 폴더 | 스터디 |
|---|---|
| `1_나만의캐러셀만들기/` | 내 인스타 계정으로 디자인 시스템과 캐러셀 만들기 |

## 시작하는 법
1. Claude 데스크톱 앱(Code 탭)에서 **스터디 폴더**(예: `1_나만의캐러셀만들기/작업절차서기반`)를 엽니다.
2. 아래 한 줄을 넣습니다.

```text
시작.md대로 진행해줘
```

약사명과 인스타 계정은 맨 위 `내정보.md`에 적어 둡니다(비어 있으면 처음에 한 번 묻고 적어 둡니다). 비밀번호·키는 적지 않습니다.

작업 결과는 그 스터디 폴더 안에 쌓입니다. 이 저장소는 비공개로 둡니다.
