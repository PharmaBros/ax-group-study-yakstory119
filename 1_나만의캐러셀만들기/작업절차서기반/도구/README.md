# 도구 — 약사님 계정 수집·분석·부품 견본·캐러셀 스크립트

약사님 인스타 계정을 **언제나 같은 방법으로** 재고 만들기 위한 고정 스크립트입니다. 전체 순서는 작업 폴더의 `작업_절차서.md`를 따릅니다. 세는 일·재는 일은 스크립트가 하고, 사람(또는 AI)은 판단만 합니다.

## 준비물

| 무엇 | 어디에 쓰나 | 확인 |
|---|---|---|
| 파이썬 3.9 이상 + Pillow + numpy | 모든 스크립트(numpy는 글꼴겹침·얼굴 검사) | `python3 -c "import PIL, numpy"` |
| 크롬 | 부품 견본·장 렌더(3·4단계) | 기본 `/Applications/Google Chrome.app`, 다른 곳이면 환경변수 `CHROME` |
| OpenCV(`.venv-cv`) | 사진보정·누끼 | `.venv-cv/bin/python -c "import cv2"` |
| swift(맥 기본) | 얼굴 겹침 검사(4단계) | `swift --version` — 없으면 검사만 건너뜀 |

## 단계별 도구

작업 폴더에서 실행합니다. `<약사님폴더>`는 작업 폴더 아래 `{표시이름}_{인스타계정}` 폴더 이름입니다. 모든 스크립트는 상대 경로를 작업 폴더 기준으로 찾고, `--help`를 붙이면 한국어 설명이 나옵니다. `--write`가 있는 스크립트는 빼면 화면에만 보여 주니, 먼저 빼고 돌려 본 뒤 저장합니다.

| 절차서 단계 | 스크립트 | 하는 일 |
|---|---|---|
| 1단계 3 | `캡션합치기.py` | Aside로 받은 캡션 전문을 게시물목록.json에 검증하고 합침 |
| 1단계 7 | `한눈에보기.py` | 편마다 모든 장을 한 장으로 모은 그림 |
| 1단계 10 | `수집검증.py` | 수집이 끝났는지 — 마지막 줄 "통과" |
| 2단계 1 | `슬라이드실측.py` · `캡션통계.py` | 비율·장 수·색 / 캡션 글 버릇·종류 비율·주당 편 수 |
| 2단계 2 | `모양표집계.py` | 장별 모양 판정을 세어 부품(2편 이상)·드묾을 가름 |
| 3단계 1~4 | `부품/` 도구 · `값검사.py` | 부품 견본 만들기·확인·블라인드(아래 "부품 견본 도구") |
| 3단계 5~6 | `디자인시스템변환기.py` · `구성샘플.py` | 화면 파일(`project/`) 만들기 / 구성안 순서로 부품 렌더 이어 붙이기 |
| 4단계 2 | `사진재료.py` | 글자 없는 본인 사진이 몇 장인지(장 구성 전에 — 모자라면 담당자에게 알림) |
| 4단계 3 | `비슷한장검사.py` | 한 편 안·최근 3편과 비슷한 장·같은 사진(`--약사님폴더`를 주면 그림으로 같은 컷까지) 검사 |
| 4단계 5 | `부품/사진준비.py` · `부품/사진보정.py` · `부품/누끼.py` | 기존 사진에서 얹힌 글만 지우기(상자 글 메움·사진 위 글 지움·얼룩 덮기) |
| 3단계 1 · 4단계 2·5 | `부품/gpt그림.py` | GPT 키가 있을 때: 그림 새로 만들기(`만들기`) · 사진의 지정한 자리만 고치기(`고치기`, 자리 밖은 원본 그대로). 키는 `키확인`으로 보고 `키넣기`로 넣는다(맥 = 키체인, 윈도우 = 작업 폴더 `.env`). 규칙은 절차서 0-3·0-4 |
| 4단계 6 | `장만들기.py` · `부품/얼굴.py` · `값검사.py` · `부품/글자대조.py` | 견본을 틀로 새 장 만들기(사진마다 글 자리가 다르면 장.json `요소`) + 얼굴 겹침·값·오타 검사 |
| 4단계 7 | `캐러셀아티팩트.py` | 장 그림 + 캡션을 아티팩트 페이지(`아티팩트/캐러셀.html`)로 |
| 4단계 8 | `편블라인드.py` | 만든 장 + 같은 부품 원본 장을 섞은 블라인드 판·정답·판정 지시문 |

장 크기는 부품마다 다릅니다: 부품 `요소.json`의 `"크기": [1080, H]` → `견본.json`(없으면 계정 `디자인시스템.json` `출력_크기_기본`, 그것도 없으면 1080×1350). **한 편 안 장은 모두 같은 크기**여야 해서 `장만들기.py`·`비슷한장검사.py`는 섞인 부품에서, `캐러셀아티팩트.py`는 섞인 render.png에서 실패합니다(캐러셀·편블라인드는 첫 장 render.png 크기를 따름). `부품/글꼴겹침.py`는 `--높이 H`.

```bash
python3 -I 도구/수집검증.py   <약사님폴더> --write
python3 -I 도구/슬라이드실측.py <약사님폴더> --write
python3 -I 도구/한눈에보기.py  <약사님폴더>
python3 -I 도구/캡션통계.py   <약사님폴더> --write
python3 -I 도구/모양표집계.py  <약사님폴더> --write
```

## 수집·분석 도구가 보는 것

1. **수집검증** — 수집이 끝났는지 확인. 캡션이 잘렸는지(최장 300자 이하면 잘림 의심), 편 안에 같은 그림이 두 번 있는지, 표지 가로 1080 미만 편, `출처.json` 없는 편, 01 하위 폴더·파일 유무. 마지막 줄이 "통과"가 아니면 수집부터 보완합니다. **"확인 필요" 건수는 절차서 1단계 10의 ①~④(캡션·같은 그림·표지 해상도·출처.json)만 셉니다.** 01 하위 세트·읽어주세요·동의기록·분류.md·한눈에보기 유무는 "참고(건수에 안 셈)" 절에만 나옵니다. `출처.json`에 `"해상도": "낮음"`이 적힌 편은 통과, 캡션상태에 "잘림"이 든 항목의 � 글자는 인스타 한계라 건수에서 뺍니다.
2. **슬라이드실측** — 편마다 표지 크기·비율·장 수·밝기·주요 색. 계정 전체 비율 분포, 종류별 장 수, 유채색 상위 10개, 강조색 후보(참고).
3. **한눈에보기** — 편마다 모든 장을 한 장으로 모은 그림(가로 5장, 장당 360px). 사람이 디자인 버릇을 볼 때 씁니다.
4. **캡션통계** — 캡션의 글 버릇(끝맺음·존댓말·1인칭·이모지·불릿·해시태그·CTA·광고 표시·자주 쓰는 표현·첫 줄 모양)과 주당 편 수(격자 최근 60편, 릴스·개인 일상 포함, 고정 게시물 제외 — 표시 없는 고정도 앞 3자리 날짜로 걸러냄). 글 버릇은 개인 일상을 기본 제외.

**`02/분류.md`를 고쳤다면**(종류를 다시 판정했거나 대표 편이 바뀜) 2번 슬라이드실측과 4번 캡션통계를 `--write`로 다시 돌리고, 분석 메모·설계서의 `[도구]` 칸을 새 출력으로 바꿉니다. 종류 비율·종류별 장 수가 분류.md를 읽기 때문입니다. 옛 출력 파일은 지우지 않습니다(같은 날이면 덮어써지니, 남겨야 하면 먼저 이름 끝에 `_이전`을 붙여 두세요).

## 설계서 칸 ↔ 스크립트

설계서 칸(`작업_절차서.md` 부록 B) 가운데 `[도구]` 표시 칸은 스크립트 출력을 그대로 옮기고, 나머지는 사람이 한눈에보기와 원본 장을 보고 적습니다. 스크립트가 못 재는 칸은 비워 두지 말고 "측정 불가(이유)"라고 적습니다.

| 스크립트 | 값을 주는 설계서 칸 |
|---|---|
| 수집검증 | 기본(분석한 게시물 수) |
| 캡션통계 | 종류 비율·주당 편 수 · 말투(캡션): 끝맺음·존댓말·1인칭·이모지·불릿·해시태그·CTA·광고 표시·자주 쓰는 표현·첫 줄 모양 |
| 슬라이드실측 | 슬라이드 비율 · 종류별 평소 장 수 · 색(바탕 색들, 강조색 후보는 참고) |
| 모양표집계 | 부품(이름·계열·편·장 수·쓰는 종류·편 안 자리·근거 장·견본 장 후보) · 종류별 장 순서 · 바탕 비율 |

- 색은 면적 상위가 바탕색입니다. 강조색 후보 표는 참고용이고(단색·그래픽 장의 채도 높은 색만 셈 — 얇은 글자색은 못 잡을 수 있음), 글자 강조색은 한눈에보기에서 사람이 고릅니다.
- 글자 크기·여백·글꼴은 스크립트가 주지 않습니다. 사람이 재고, 손글씨·특이한 글꼴 자리는 `부품/글꼴겹침.py`로 잽니다.

## 자주 쓰는 옵션

- `캡션통계.py --캡션파일 <json>` : 캡션 전문이 다른 파일(키 `캡션전문`)에 있을 때만 씁니다(캡션합치기로 `게시물목록.json`에 합쳤으면 필요 없음).
- `캡션통계.py --포함개인일상` : 개인 일상 캡션도 함께 셉니다.
- `슬라이드실측.py --포함개인일상` : 개인 일상 종류 편도 잽니다(기본은 뺌).
- `슬라이드실측.py --편 5` / `한눈에보기.py --편 5` : 앞 5편만(시험용). `--종류 "공구 안내"` : 그 종류만.
- `한눈에보기.py --출력 <폴더>` : 약사님 폴더 대신 다른 폴더에 만듭니다(시험용).

## 알아 둘 것

- 실패하면 `[실패] …` 로 시작하는 한국어 메시지가 나옵니다(폴더를 못 찾음, json 깨짐 등).
- 캡션 원문은 어느 출력에도 싣지 않습니다(통계만). 멘션·자주 쓰는 표현은 통계로 그대로 나옵니다.
- 색 값은 모든 장을 32단위로 뭉쳐 센 평균이라 실제 디자인 색과 조금 다를 수 있습니다. "배경이 사진인지"는 추정입니다. 글자 크기는 재지 않습니다(정확도 낮음 — 사람이 봅니다).
- 테스트: `python3 -m unittest discover 도구/tests` (실제 약사님 자료는 쓰지 않음).

## 비슷한 장 검사 (작업 절차서 4단계 3)

캐러셀 한 편의 장 구성이 "비슷한 장 중복 금지"를 지키는지 본다. ① 한 편 안 같은 모양 계열 2장 이상 ② 최근 3편과 표지 부품이 같음 ③ 최근 3편과 계열 순서가 똑같음 ④ 최근 3편과 같은 사진(`구성.json`의 `사진` 출처가 같음)이면 걸린다(끝 코드 1).

```
python3 -I 도구/비슷한장검사.py "<약사님폴더>/05_디자인시스템/부품" <새 편>/구성.json [최근 편 구성.json …]
```

- 계열은 부품 README의 `## 모양 계열` 다음 줄 첫머리(예: `㉡ 격자 표 — …`)에서 읽는다. 줄이 없는 부품은 "모르는 부품"으로 걸린다. 그 줄에 "최대 N장"이 있으면 그 계열은 한 편에 N장까지(없으면 1장).
- `구성.json` = `{"편": 이름, "날짜": "YYYY-MM-DD", "부품": [장 순서대로 부품 영문 이름], "사진": [쓴 사진 출처 — 원본 편 아이디·장 또는 공식 이미지 주소]}` — 편 폴더에 둔다.


## 모양표 (작업 절차서 1단계 9 · 2단계 2)

- 1단계 받아적기 때 장마다 `02_대표슬라이드/슬라이드/<편>/사진메모.json`에 `모양`·`부품`·`계열`을 적는다(절차서 부록 A-5).
- `모양표집계.py <약사님폴더> [--write]` — 부품마다 편·장 수, 쓰는 종류, 편 안 자리, 근거 장, 견본 장 후보, 종류별 바탕 비율·장 순서 예 → `03_분석/{오늘}_모양표.md`. 맨 위 "부품 판정 전 장"이 0이어야 한다. 2편 이상 = 부품, 1편 = 드묾.

## 부품 견본 도구 (작업 절차서 3단계) — `도구/부품/`

부품 폴더 = `<약사님폴더>/05_디자인시스템/부품/<부품 영문 이름>/`(요소.json → 견본.json·preview.html·render.png·cmp.jpg·README.md, 깔개·조각 그림). 크롬이 필요하고(`CHROME` 환경변수로 위치 바꿈), 사진보정·누끼는 OpenCV가 든 `.venv-cv/bin/python`으로 돌린다.

| 도구 | 하는 일 |
|---|---|
| `부품/lib.py` | 잉크 상자 재기, 글 줄 훑기(`scan`), 글꼴에 글자가 있는지(`glyph`), 크롬으로 글꼴 크기 겹쳐 맞추기, 렌더, 원본과 나란히(cmp.jpg). 글꼴 이름표가 여기 한 곳에 있다 |
| `부품/글꼴겹침.py <원본 jpg> <글자리.json> [--후보 …]` | 글 자리마다 후보 글꼴(강원교육모두 Bold/Light·싱글데이·도현·나눔스퀘어라운드·카페24 당당해·프리텐다드·지마켓) IoU와 1위, 역할별 평균 1위 → 표·비교 그림 |
| `부품/견본만들기.py <요소.json> <원본 jpg> <부품 폴더>` | 요소 → `견본.json`·`preview.html`·`render.png`·`cmp.jpg` + 글 위치 확인. 글꼴에 없는 글자는 그 글자만 프리텐다드로 |
| `부품/사진보정.py <원본> <출력_보정.jpg> --글 x0,y0,x1,y1 --방식 판\|질감\|메움 [--보호 …] [--확인]` | 얹힌 글만 지운 깔개. 머리카락·보호 상자는 그대로, `--확인`이면 판 색 기준 명암 8배 그림 |
| `부품/누끼.py <원본> <출력.png> --상자 x0,y0,x1,y1` | 단색 바탕에서 사람·그림만 알파로 떼어 냄 + 가장자리 확인 그림 |
| `값검사.py <preview·장 html> <json> [<json> …]` | 장 안 px·색이 json 값인지 — "없는 값 0건"이어야 함 |
| `부품/글자대조.py <견본.json·장 html> <글.md·장별글.md>` | 줄마다 원문에 그대로 있는지(오타 잡기). 끝 코드 1 = 없는 줄 |
| `부품/부품README.py <부품 폴더> [--모양표 …]` | 견본.json → README.md(`## 모양 계열`·편 안 자리·글 자리·고정/바꿔 끼우는 자리) |
| `부품/견본넣기.py <부품 상위 폴더> <디자인시스템.json> [--write]` | 견본을 `json_자리`(`부품.<이름>.견본`)에 넣음. 기본은 바뀔 자리만 보여 줌 |
| `부품/얼굴.py <글뺀.png> <render.png> [--확인 <jpg>]` | 글 뺀 렌더에서 얼굴 위치를 찾아(macOS Vision `얼굴찾기.swift`, 내려받는 모델 없음) 얹힌 글이 머리 상자+20px 안인지. 장만들기가 자동으로 부른다 |
| `부품/블라인드.py <약사님폴더> <부품 상위 폴더> --출력 <폴더> [--회차 N] [--재압축] [--대조 <부품>]` | 만든 장 4 + 같은 부품 원본 4를 섞은 판(A 흐린 모아보기, B 낱장), 정답표, 판정 지시문 |
| `구성샘플.py <부품 상위 폴더> <부품…> --출력 <jpg>` | 구성안 순서대로 부품 렌더를 이어 붙임 |
| `디자인시스템변환기.py` | 부품 폴더가 있으면 부품 preview·README·그림(`part-*`)·글꼴을 화면에 함께 넣고, 장 샘플은 재료.json `장`이 비어 있으면 만들지 않고(부품 견본이 있으면 비운다 — 절차서 3단계 5), 목록에서 빠진 컴포넌트 폴더는 지우며, README에 `## 부품 견본` 절 |

## 캐러셀 장 만들기 (작업 절차서 4단계 6)

- `장만들기.py <약사님폴더> <편 폴더> --장 <장.json>` — 부품 preview를 틀로 글·그림만 바꾼 `s/<n>_<부품>/slide.html`·`render.png`, `s/모아보기.jpg`. 새 글은 줄 단위로 다시 앉힌다. 사진 장은 얼굴 겹침 검사(`부품/얼굴.py`)를 해 `[얼굴]` 경고·`얼굴확인.jpg`를 남긴다.
