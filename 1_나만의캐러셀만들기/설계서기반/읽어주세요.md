# 약들약 약사님께 — 디자인 시스템 직접 만들기 묶음 (새로 설계하는 판)

## 이 묶음이 하는 일
약사님 인스타 카드뉴스의 **디자인 견본 모음**(디자인 시스템 화면)을 약사님 컴퓨터의 클로드가 직접 만듭니다. 클로드가 약사님 실제 게시물을 모두 보고 **자주 쓰시는 장 모양을 스스로 골라**, 모양마다 색·글자 크기·자리를 재서 똑같이 다시 그립니다. 그리고 실제 게시물과 섞어 놓아도 구별이 안 되는지 검사합니다. 이 견본은 나중에 노션 기획안으로 캐러셀을 만들 때 씁니다.

약사님이 하실 일은 많지 않습니다. 클로드가 일을 하고, 필요할 때만 물어봅니다.

**게시물은 다시 모으지 않아도 됩니다.** 저희가 미리 모아 둔 약사님 공개 카드뉴스(20편)와 분석 자료(캡션 통계, 그림 크기·색, 게시물 종류)가 폴더 안 `0_수집분석/`에 들어 있어요.

## 준비물
- **Claude Code 데스크톱 앱**(로그인된 상태)
- **구글 크롬**(없으면 클로드가 알려 드려요 — 무료)
- 파이썬 같은 프로그램은 클로드가 확인합니다. 설치 창이 뜨면 "설치"만 눌러 주세요.
- 인스타그램 로그인은 필요 없습니다.

## 시작하는 법
1. 받은 압축 파일을 원하는 곳(예: 문서 폴더)에 풉니다. `약들약_디자인시스템_새로만들기` 폴더가 생깁니다.
2. Claude Code 데스크톱 앱에서 **그 폴더를 엽니다**.
3. 클로드에게 이렇게 한 줄 보냅니다:
   > **시작.md대로 진행해 줘**

## 중간에 클로드가 물어보는 것
- **고른 장 모양 확인** — 클로드가 약사님 게시물에서 고른 대표 게시물과 장 모양 목록을 그림과 함께 보여 드려요. 빠진 모양이나 요즘 안 쓰시는 모양이 있으면 알려 주세요(답이 없어도 진행합니다).
- 약사님만 아는 것 — 그림(아이콘·캐릭터)을 어디서 가져오셨는지, 글을 얹기 전 원본 사진이나 캔바 파일이 있는지, 쓰신 글꼴 이름 같은 것. 모르시면 "모름"이라고 하셔도 됩니다.
- **허락** — 파일 내려받기, AI 그림 만들기(돈이 들 수 있어요), 완성본을 Claude 아티팩트(처음엔 약사님만 보는 비공개 페이지)로 올리기.
- 클로드는 **비밀번호·결제·약관 동의를 하지 않습니다.** 그런 화면은 약사님이 직접 해 주세요.

## 걸리는 시간
- 게시물 보기·설계: 클로드가 일하는 시간으로 몇 시간
- 견본 만들기·검사: 몇 시간 더(여러 번 나눠 해도 됩니다 — 다시 열고 "이어서 진행해 줘"라고 하면 멈춘 곳부터 합니다)

## 끝나면 남는 것
- 약사님의 **디자인 시스템 화면 주소**(Claude 아티팩트)
- 폴더 안 `7_결과/` — 설계 기록(`설계/`), 견본 파일, 비교 그림, 블라인드 검사 결과, `기록/끝_기록.md`
- 끝나면 `2_커스텀설계서` 폴더, `5_글꼴/글꼴표.json`, `7_결과/설계` 폴더와 `7_결과/기록` 폴더를 앤서니에게 보내 주세요. 같은 내용으로 맞춰 둡니다.

## 디자인 시스템 다음 — 캐러셀 만들기까지
디자인 시스템 화면이 끝나면(13단계) 같은 폴더에서 노션 기획안으로 **캐러셀을 만들고 검수**하는 데까지 이어서 할 수 있어요(14~22단계). 기획안 주소를 클로드에게 주시면 됩니다.
- **AI 알약 그림은 선택**이에요. 약사님 사진에 없는 알약을 상표 없는 그림으로 그려 넣을 수 있는데, OpenAI 키가 있어야 하고 그림 한 장마다 사용료가 나가요. 안 쓰셔도 됩니다(실사·원본 조각·글로만 만들어요).
