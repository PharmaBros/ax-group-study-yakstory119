## 편 폴더 이름 규칙

`게시물/<게시 날짜>_<아이디>/`
- 게시 날짜 = 한국 날짜(`YYYY-MM-DD`). 아이디 = 인스타 주소 `instagram.com/p/<아이디>/`의 그 글자.
- 안에 `1.jpg, 2.jpg …` = 장 순서 그대로. 번호가 빠진 장은 없다.
- `출처.json` = 주소·게시일·분류·`장수`(붙여 씀)·받은날·원본 해상도·**`영상 장`**(영상이라 미리보기 그림만 있는 장 번호 — 작고 흐리므로 색·크기를 재거나 견본·블라인드에 쓰지 않는다). 사본에서 가린 장이 있는 편은 **`가린 곳`** 칸이 더해져 있다(가린 자리는 재지 않는다).
- `글.md`(장별 글을 받아 적은 것)는 `2026-10-28_DfBarTaE3Uh`·`2026-11-01_DfMrUkUE4nX` 두 편에만 있다.
- 그림 크기는 편마다, 장마다 다르다(1600×2000, 1440×1800, 1320×1649, 720×900 등). **비율은 모두 세로 4:5**다. `출처.json`의 `원본해상도`는 그 편 첫 장 크기라, 첫 장이 영상(720×900)인 편도 2장부터는 더 큰 그림일 수 있다 — 편별 표는 `3_작업안내/약들약_작업안내.md` 1장.
- 종류는 `분류.md`가 기준이다. `출처.json`의 `분류`와 다른 편이 둘 있다(De_h2e0E8Oa·Deq1DhIE0Dr — 분류.md의 '영양제 트렌드'가 맞다).

## 분석 문서 속 옛 경로 읽는 법

분석 문서는 우리 쪽 보관 폴더 이름으로 경로를 적었다. 이 묶음에서는 아래처럼 읽는다.

| 문서에 적힌 경로 | 이 묶음 안 자리 |
|---|---|
| `01/게시물목록.json`·`01_수집_인스타게시물/…`·`01/프로필.md` | `0_수집분석/게시물목록.json`·`프로필.md` |
| `02/슬라이드/<편>/`·`02_대표게시물_슬라이드/슬라이드/<편>/` | `0_수집분석/게시물/<편>/` |
| `02/분류.md` | `0_수집분석/분류.md` |
| `03_분석_계정특징/2026-11-03_1단계_실측.md` 등(`2026-11-03_` 머리) | `0_수집분석/1단계_실측.md`·`캡션통계.md`·`슬라이드실측.md` |
| 계정별메모·0단계 메모·커스텀 설계서(우리가 쓴 설계 문서) | 묶음에 없음 — 이번에 약사님 쪽에서 새로 만든다(`7_결과/설계/`·`2_커스텀설계서/`). `1단계_실측.md`의 "0단계 메모 값과 비교"는 우리 쪽 옛 메모와 견준 기록이다 |
| `설계서/공통/작업_설계서.md`·`도구/…`(수집검증·캡션통계 도구 등)·`git-docs/…` | 묶음에 없음(우리 쪽 작업 문서·도구) — 필요 없다 |
| `한눈에보기/`, `_결정전`·`_수정전`·`_잘림표시전` 같은 옛 판, Apify 원본 json, 검수 기록(`04_설계서검토/…`), `05_동의와설정/…`, `수집검증` | 묶음에 없음(넣지 않음) |
| 우리가 만든 디자인 시스템 화면·부품 견본·그림 조각·완성 캐러셀 | 묶음에 없음 — 이번에 약사님 쪽에서 새로 만든다 |

- 문서에 나오는 `계정A`~`계정G`(약들약 = 이 계정 자신이라 이름 그대로)는 다른 약사님 계정 이름을 가린 것이다.
- 분석 문서의 숫자(편 수·장 수)는 그 문서를 쓴 때 기준이라 서로 다를 수 있다.
- 캡션통계·슬라이드실측의 `[도구]` 칸 안내, "대표 hex" 같은 말은 우리 쪽 도구가 쓴 말이다. "대표 hex"는 32단위로 뭉친 색 값이라는 뜻이고 대표 편과는 상관없다.
