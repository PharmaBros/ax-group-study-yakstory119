# 도구 사용법

- 모두 **파이썬 표준 + Pillow**만 쓴다. 묶음 폴더에서 `python3 -I 6_도구/<도구>.py …`로 돌린다(경로는 인자로 받으므로 묶음을 어디에 두어도 된다).
- 인자 없이 돌리면 사용법이 나온다.

| 도구 | 하는 일 | 쓰는 단계 |
|---|---|---|
| `합치기.py` | 공통 json + 커스텀 json → 최종 json | 0(시험)·5·6·7·11 |
| `값검사.py` | preview.html 장 안 px·hex·글꼴이 최종 json에 있는지 | 7·9·11 |
| `그림찍기.py` | preview의 장만 크롬으로 1080×1350 PNG | 8·9·11 |
| `나란히보기.py` | 만든 그림·원본 그림 나란히 | 9·11 |
| `블라인드묶음.py` | 만든 4 + 원본 4 → 번호 붙인 판정용 그림·정답·질문 | 10·11 |
| `토큰만들기.py` | 최종 json + 글꼴표 → project/tokens.json | 6(시험)·12 |
| `게시준비.py` | `__BLOB__` 그림 이름 → 올린 주소, bundle.js | 12 |
| `알약그림.py` | (선택) 상표 없는 일반 알약 그림 — 키·허락 있을 때만 | 17(캐러셀) |
| `AI그림검사묶음.py` | AI 그림 티 검사 묶음 만들기 | 20(캐러셀) |
| `비슷한장검사.py` | 부품 README '## 모양 계열' 읽기 확인(다음 단계에서는 편 구성 검사) | 7(확인)·다음 단계 |

## 합치기.py
```
python3 -I 6_도구/합치기.py 2_커스텀설계서            # 보고만(파일 안 바뀜)
python3 -I 6_도구/합치기.py 2_커스텀설계서 --write    # 최종 json 저장
```
- 커스텀 json을 고친 뒤에만 `--write`. 최종 json은 손으로 고치지 않는다.
- 커스텀 json이 빈 틀이면 "덮은 칸 0 · 새 칸 0"이 나온다(정상). 5단계에서 채운 뒤에는 "덮은 칸·새 칸"이 늘고, "아직 고르지 않은 선택지"는 이 계정 값을 골라 적은 칸만큼 줄어든다. 남은 선택지는 커스텀 설계서에 "고르지 않음(까닭)"으로 적는다.

## 값검사.py
```
python3 -I 6_도구/값검사.py 7_결과/디자인시스템화면/project/components 2_커스텀설계서/디자인시스템_최종.json
```
- 부품마다 "없는 값 n건"과 그 값이 나온다. 모두 0건이어야 한다.
- 장 안(`class="slide"` 안쪽) 요소의 `style="…"`만 본다. `<style>` 블록 안 값은 안 본다.

## 그림찍기.py
```
python3 -I 6_도구/그림찍기.py 7_결과/디자인시스템화면 7_결과/기록/그림 [부품 …]
```
- 그림은 `7_결과/디자인시스템화면/올릴사진/`에서 찾는다(바로가기 권장 — 공통설계서 1장).
- 글꼴은 `project/tokens.json`(있으면)과 `5_글꼴/글꼴표.json`의 `fonts`에서. `fonts`는 6단계에서 채운다(비어 있으면 모든 글이 기본 고딕으로 찍힌다). 파일이 없으면 "글꼴 파일 없음"을 알려 준다.
- 크롬이 다른 곳에 있으면: `CHROME="/경로/Google Chrome" python3 -I 6_도구/그림찍기.py …`

## 나란히보기.py
```
python3 -I 6_도구/나란히보기.py <만든.png> <원본.jpg> <출력.jpg>
```
- 왼쪽 = 만든 것(MADE), 오른쪽 = 원본(ORIGINAL). 결과를 Read로 연다.

## 블라인드묶음.py
```
python3 -I 6_도구/블라인드묶음.py --만든 a.png b.png c.png d.png --원본 1.jpg 2.jpg 3.jpg 4.jpg --출력 7_결과/블라인드/1회차
```
- 회차마다 새 폴더. 원본은 세로 4:5(3:4는 위아래 조금 잘라 맞춤), 정사각은 거절.
- 판정자에게는 `질문.txt`의 문장과 자기 그림만 준다(A = `g/blur.jpg`, B = `g/tile_1~8.jpg`). `key.json`은 판정이 끝난 뒤에 연다.

## 토큰만들기.py
```
python3 -I 6_도구/토큰만들기.py 2_커스텀설계서/디자인시스템_최종.json 7_결과/디자인시스템화면/project --이름 약들약_yakstory119
```
- `project/fonts/`에 글꼴을 먼저 복사해 둔다. 제목 글꼴·글씨 역할표·굵기는 `5_글꼴/글꼴표.json`의 `제목글꼴`·`families`·`굵기`에서 읽는다 — 6단계에서 채운다. **`제목글꼴`이 비어 있으면 도구가 이 계정과 상관없는 이름을 넣으므로** 채운 뒤에 돌리거나 `--제목글꼴 "글꼴 이름"`을 준다.
- 예전 tokens.json은 `tokens_이전_<날짜시각>.json`으로 이름만 바뀐다.

## 게시준비.py
```
python3 -I 6_도구/게시준비.py 7_결과/디자인시스템화면 Yakstory119 <부품1> <부품2> …   # 순서 = 7_결과/설계/부품목록.md 화면 카드 순서
```
- `7_결과/디자인시스템화면/사진아이디.json`에 `{"파일이름": "올린 주소"}`가 모두 채워져 있어야 한다.
- 결과는 `7_결과/디자인시스템화면/게시용/`. 예전 게시용은 이름만 바뀐다.

## 비슷한장검사.py
```
python3 -I 6_도구/비슷한장검사.py 7_결과/디자인시스템화면/project/components <구성.json>
```
- 구성.json 예: `{"편":"확인","날짜":"2026-11-20","부품":["<부품1>","<부품2>", …],"사진":[]}`
- 부품마다 계열 이름이 나오면 README의 `## 모양 계열` 줄이 잘 읽히는 것이다. 부품을 모두 넣으면 같은 계열끼리 "걸림"이 나오는 것이 정상이다(확인용).

## 알약그림.py (선택 — 캐러셀 17단계에서만)
```
python3 -I 6_도구/알약그림.py --키확인
python3 -I 6_도구/알약그림.py --허락 --바탕 <배경 사진> --알약 "흰 원형 정제 2알, 노란 연질캡슐 1알" --출력 8_캐러셀/<편>/img/알약_<이름>_AI생성.png
```
- 사진에 없는 알약을 **상표 없는 일반 알약 그림**으로 그린다(GPT). 그 약사님 게시물 실사 → 공식 사이트 실사 → 둘 다 없을 때만 쓴다. 상표·라벨 글자·성분표·사람은 그리지 않는다.
- OpenAI 키가 키체인(`openai_api_key`)에 있어야 한다 — 약사님이 직접 등록한다(시작.md "0단계 선택"). 클로드는 키를 묻거나 보거나 적지 않는다. `--키확인`은 값을 보이지 않고 "키 있음/없음"만 알려 준다.
- 한 번 실행 = 그림 1장 사용료. 그릴 때마다 약사님께 장 수·대략의 비용을 묻고 허락을 받은 뒤 `--허락`을 붙인다.
- 출력 이름에 `_AI생성`이 없으면 멈춘다. 받은 그대로의 파일은 `_AI원본/`에 남고, AI 표시(C2PA)는 지우지 않는다. `--결맞춤 <그림> --기준 <원본 실사>`로 같은 계정 실사와 색·결을 맞출 수 있다.
- 커스텀 설계서·작업안내에 "AI 그림 안 씀"이 있으면 키가 있어도 쓰지 않는다.

## AI그림검사묶음.py (캐러셀 20단계 검수)
```
python3 -I 6_도구/AI그림검사묶음.py --편 8_캐러셀/<편> --출력 8_캐러셀/<편>/검수/AI그림 [--원본 <원본 조각 ...>]
```
- 한 편에 쓴 `_AI생성` 그림과 같은 계정 원본 조각을 섞어 번호만 붙은 격자(`grid.jpg`)·낱장·정답(`key.json`)·판정자 질문(`질문.txt`)을 만든다. 판정자는 만든 대화와 다른 새 대화로 한다.
- AI 그림을 쓰지 않은 편이면 돌리지 않는다.

비슷한장검사.py는 캐러셀 15단계(장 구성)와 18단계에서도 쓴다: `python3 -I 6_도구/비슷한장검사.py 7_결과/디자인시스템화면/project/components 8_캐러셀/<편>/구성.json [최근 편 구성.json …]` — 한 편 안 같은 모양 계열 1장, 최근 3편과 표지·순서·사진이 겹치지 않음, **배경 그림 중복 금지**(편 폴더에 index.html이 있으면 장마다 깐 배경을 그림 내용으로 견줌)를 본다. 통과하면 0으로 끝난다.
