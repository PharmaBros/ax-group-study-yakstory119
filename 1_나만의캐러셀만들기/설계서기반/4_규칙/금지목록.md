# 금지 목록

계속 늘려 가는 목록. 계정별 금지어는 각 커스텀 설계서 3장. 검수는 이 목록과 계정별 금지어를 합쳐 본다. (초안: 식약처 표시·광고 가이드를 바탕으로 한 것이며 사용자 검토 전)

## ① 광고 심의 위반 표현

효능을 단정하거나, 약사의 권위·체험으로 효과를 보증하는 말은 슬라이드와 캡션 모두에 쓰지 않는다.

- 치료된다 / 치료에 좋다 / 완치
- 부작용 없음 / 부작용 걱정 없이
- 100% 효과 / 100% 안전
- 최고 / 1위 / 가장 좋은 (근거 없는 최상급)
- 약사 추천형("약사로서 추천 / 약사 픽 / 약사가 먹는") — **공통 최소선(2026-11-03 사용자 결정)**: "약사가 추천"이 효능 단정("당장 드세요", "염증 50% 감소", "○○에 효과")과 **한 문장·한 장에 붙으면 금지**. "약사가 만든/개발한/배합한"처럼 사실만 적는 표현은 허용. 그 위에서 "약사 픽", "약사가 추천하는 ○○"을 쓸지는 **약사님별 커스텀 설계서 3장에서 정한다**(그 계정의 어투이면 허용). 슬라이드 안 글에만 적용(캡션은 결정 2대로 그대로)
- "먹고 나았어요" 같은 효능 체험담
- 인정받지 않은 기능성·질병 표현(예: 암 예방, 당뇨 개선)
- 즉시 효과 / 확실히 달라집니다
- 최저가 / 국내 유일 / 최초 — 근거가 대본에 있을 때만. 할인율·정상가는 노션 대본 값만 쓴다
- 건강기능식품에 의약품 용어 쓰지 않기: "복용"→"섭취", "처방", "약효", "치료제"
- 인정받은 기능성 문구는 원문대로("~에 도움을 줄 수 있음"을 "~에 좋다"로 줄이지 않는다)
- 다른 업체·제품 비방. 비교는 객관적 자료가 대본에 있을 때만 → 검수 [판단]
- 전문의약품 제품명은 정보 제공까지만. 구매·추천 유도와 묶이지 않게 → 검수 [판단]

## ② AI 티 나는 어휘·구문

기계가 쓴 글처럼 읽히는 말투. 그 약사님 커스텀 설계서 3장 "자주 쓰는 표현"에 있는 말은 이 목록에서 뺀다(예: "여러분"을 평소에 쓰는 계정이면 통과).

### ②-1 우리가 처음 적은 것
- "~에 대해 알아보겠습니다" / "함께 알아볼까요"
- "~하는 것이 중요합니다"
- "결론적으로" / "요약하자면"
- "놀랍게도" / "주목할 만한"
- "~의 모든 것" / "총정리"
- 기계적인 3개 나열 (글자로 못 거름 → 검수 [판단] 항목)
- 문장마다 이모지, 과도한 이모지 나열 (글자로 못 거름 → 검수 [판단] 항목)
- "여러분" 반복

### ②-2 im-not-ai에서 가져온 것 (결정 19)
출처: im-not-ai 스킬 `humanize-korean` v2 `quick-rules.md`(MIT, 2026-11-02 설치본). 카드뉴스 슬라이드 글과 캡션에 맞는 패턴만 골랐고, 번호는 원본 ID. S1 = 보이면 바로 고침, S2 = 반복될 때만.

**번역투 (A)**
- A-3 [S1] "~에 있어(서)" → "~에서", "~을 볼 때"
- A-7 [S1] "가지고 있다", "~을 제공한다" 식 영어 직역 → "경쟁력을 가지고 있다"는 "경쟁력이 강하다"
- A-8 [S1] 이중 피동 "~되어진다", "~지게 된다" → "~된다"
- A-9 [S2] "~에 의해" → 행위자를 주어로("아연에 의해 흡수가" → "아연이 흡수를")
- A-15 [S2] 추상 주어 + 만능 동사("연구가 보여준다", "식단이 제공한다") → 구체 주어
- A-21 [S2] "단순한 X를 넘어 Y" → "X만이 아니라 Y"
- A-22 [S2] "~은 명확하다/분명하다" → 그냥 단언
- A-24 [S2] "더 이상 ~ 아니다" 2회+ → "이제 ~"

**AI 관용구 (D)**
- D-1 [S1] "결론적으로 / 따라서 / 이를 통해 / 그러므로 / 요약하면 / 정리하자면" — 한 편에 1개까지
- D-2 [S1] "시사하는 바가 크다 / 주목할 만하다 / 매우 중요하다" → 삭제하거나 구체 결론
- D-3 [S1] "크게 세 가지로 나눌 수 있다 / 다음과 같은" 도입구 → 바로 본론
- D-5 [S2] 의인화 추상 주어("몸이 말한다", "시대가 요구한다")
- D-6 [S2] 결말 공식 "~할 때입니다 / ~시점입니다"
- D-7 [S2] "X에서 Y로", "X를 넘어 Y로" 변환 공식
- D-8 [S2] "중요한 것은 ~이다 / 핵심은 ~다 / 관건은 ~다" → 주어-서술 직결
- D-9 [S2] "~로 이어진다 / ~에 직결된다", 결산용 "결국" 2회+
- D-10 [S2] "~하는 이유다" 도치 결산
- D-12 [S2] "과제도 남아 있다 / 한계도 분명하다" 문패 문장
- D-14 [S2] 감각 술어 평가("경고는 아프다"), 사전 은유(잠식·청사진·적신호·신호탄·뿌리내리다)

**구조·형식명사 (C·F·I)**
- C-7 [S2] 문두 "먼저–반면–결국" 3단 공식
- C-9 [S2] "1) 2) 3)" 괄호 번호 나열 — 단 카드뉴스의 번호 배지·순위 표시는 디자인이므로 제외
- F-5 [S2] "~적 N" 추상 체인("전략적 함의", "근본적 해결") 3회+
- I-2 [S2] "주목할 점은 ~ / ~라는 점에 있다"
- I-3 [S2] "~다는 것이다 / ~다는 뜻이다" 결말 2회+

**일부러 뺀 규칙(카드뉴스·인스타에는 안 맞음)** — C-2(불릿 금지), C-5(이모지 전부 삭제), J-1(볼드 제거), E-1(문장 길이 섞기), B-1(영어 병기), H·G 대부분. 이모지·불릿·강조는 그 약사님 설계서 값이 기준이다.

**지켜야 할 원칙(원본의 Do-NOT, 우리에게 더 중요)**
- 제품명·성분명·수치·단위·날짜는 손대지 않는다.
- **유보 표현을 단정으로 바꾸지 않는다.** "~에 도움을 줄 수 있음"은 그대로(의학 텍스트 예외 = 우리 ①의 기능성 원문 규칙과 같다).
- 윤문은 덜어내기만. 새 비유·상투구를 심지 않는다. 변경률 30% 넘으면 되돌린다.

## ③ 표시 의무 (광고·협찬·공구)

경제적 대가(판매 수익·수수료·제품 제공)가 있으면 캡션 첫 부분이나 끝에 "광고", "협찬", "유료광고", "공동구매(판매자 본인)"처럼 본문과 구분되게 표시한다(공정위 추천·보증 심사지침). 해시태그 더미 사이에 묻히거나 "더 보기"를 눌러야 보이는 위치는 안 된다. 공구 안내·제품 소개 편은 이 표시가 있어야 통과하며, 문구·위치는 그 약사님 커스텀 설계서 3장 "광고·공구 표시 방식"을 따른다.
